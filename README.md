# 『VoxelBrain』（Rev. 3.0 仕様骨子）

## 1. コア・スケールとGPU最適化（The 4×4×4 Pivot）
- **基本計算単位（1脳）：**
  - **$4 \times 4 \times 4 = 64$ セル**（完全な解剖学的ホワイトボックス）。
- **GPUスレッドグループ設計：**
  - `[numthreads(4, 4, 4)]`（**64スレッド**）。
  - NVIDIA Warpサイズ（32）のちょうど2倍。ダイバージェンスゼロ、Occupancy（占有率）100%のハードウェア神サイズ。
- **メモリ配置（共有メモリ `groupshared`）：**
  - 状態量 $x \in [-1.0, 1.0]$：half/float（約 128 Byte）
  - 重み $W \in [0, 255]$：**`uint8`（1Byte）** $\implies 64 \times 28 = 1,792$ Byte
  - **1脳あたりの共有メモリ消費：わずか約 2 KB！**
  - 学習の微小更新 $\Delta W$ は **確率的丸め（Stochastic Rounding）** でアンダーフローを完全防止。
- **超並列バッチ（巨大生態系）：**
  - `Dispatch(128, 64, 1)` 〜 `Dispatch(128, 128, 1)` により、**8,192 〜 16,384 個体**を1フレーム内で同時シミュレーション。
  - 最適化探索の域を超えた「超巨大個体群による群淘汰（空間生態系）」を実現。

## 2. 配線トポロジー：デールの原理と「軸索誘導場」
- **デールの原理（Dale's Principle）：**
  - 興奮性 $[0, 1]$ と 抑制性（GABA） $[-1, 0]$ を細胞極性として完全分離。
  - シナプス重みは非負クランプ $W_{ij} \in [0, 255]$（配線の太さのみを表現）。
- **27近傍（局所協調）：**
  - 3D Moore近傍（自セル＋26近傍）。局所の遅延線・積分ループ・相互抑制を担保。
- **第28結合（スモールワールド軸索 ＆ 軸索誘導）：**
  - 単なる `mod`（トーラス）を廃止し、**パーリンノイズによる3Dベクトル場（Flow Field）** を採用。
  - 接続先： $`\vec{P}_{\text{target}} = \vec{P}_{\text{self}} + \text{round}\Big( R \cdot \vec{V}_{\text{noise}}(x, y, z) \Big)`$
  - **軸索リーチ $R$：** 成長・変異パラメータ。
  - **利点：** 空間拡張時（サイズ増設時）にも既存ブロックの配線関係が破壊されず、連続的に新設領域へ軸索を伸ばせる。

## 3. 力学系回路の創発ポテンシャル（内包されるプリミティブ）
人間がコードを書かずとも、物理制約と淘汰によって自律創発するコア構造群：

1. **$2 \times 2 \times 2$ 最小PID制御ユニット：**
   - P：直結ショートカット
   - D：ディレイライン（遅延）＋ GABAインバーターによる時間差分
   - I：相互興奮性リカレントループ（神経積分器 / ワーキングメモリ）
   - ※64セル空間にはこのPIDユニットが **最大8個** 幾何学的に内包可能。
2. **if文のない「脊髄反射（Reflex Arc）」：**
   - 普段は非線形減衰で眠っている強結合ショートカットが、急激な大外乱（急カーブ・障害物）で閾値を突破した瞬間、1ステップで運動野へ直撃。超信地旋回をキメる。
3. **前向き内部モデル（Forward Model / 予測符号化）：**
   - モータ指令のコピー（遠心性コピー）を中間層ループへ流し込み、環境遅延を先回り予測（スミス予測器）。
   - 予測と一致していれば静寂（省エネ）、予測が外れた時（予測誤差）のみ反射を起爆。
4. **自律CPG（探索スイング）：**
   - ライン完全喪失時、抑制が外れてリミットサイクル（周期的首振り）に相転移し、再探索を行う。

## 4. 進化スケーリング：複製バグ（全ゲノム重複）戦略
- **フェーズ1：最小受肉（ $4 \times 4 \times 4$ ）**
  - まずはライントレース等の単一タスクで、反射と内部モデルを備えたエリート脳を高速育成。
- **フェーズ2：複製バグ合体（ $4 \times 8 \times 4$ ・大脳半球化）**
  - 成功したエリート重みを丸ごとコピペ複製し、左右に合体（128セル）。
  - **左半球：** 既存タスク（生存・走行）の維持。
  - **右半球：** 冗長性により自由に突然変異（障害物回避・速度制御などの新機能獲得）。
- **フェーズ3：脳梁の架橋**
  - 軸索リーチ $R$ を突然変異で増大させ、第28結合を反対側の半球へ突き刺して「脳梁（Corpus Callosum）」を形成・統合。
