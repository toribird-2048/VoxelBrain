# VoxelBrain (Rev. 4.1)


## 1. プロジェクト哲学と基本コンセプト

- **受動的記号処理からの完全脱却:**  
  極小 3D 空間の中で 24 時間自律振動・思考し続ける **「生きている非線形力学系知能」** を確立する。
- **局所性（Locality）への絶対的信仰:**  
  大域オプティマイザや全結合アテンションを否定。局所的な近傍相互作用の連鎖のみから、大域的知能（PID、予測、反射、歩行）を自律創発させる。
- **非同期受肉（Asynchronous Embodiment）:**  
  - **GPU 0（物理環境）:** 剛体力学、慣性、非線形摩擦、センサノイズ（独自の高周波物理クロック）。
  - **GPU 1（知能核）:** VoxelBrain 群（独自の神経力学系クロック）。
  - 通信ジッターやサンプリング遅延が渦巻く開放系において、排他ロックフリーな非同期分散結合を実現する。

## 2. コア・ニューロダイナミクス（The Compute Core）

GPU シリコンの物理構造と神経解剖学の完全調和。

### 空間スケールとハードウェア・マッピング
- **思考核:** `4 × 4 × 4 = 64` セル（1脳 = `[numthreads(4, 4, 4)]` = 2 Warps）。
- **レジスタ富豪型アロケーション（Occupancy 75% 戦略）:**  
  SM あたりの最大常駐ブロック数制約（16〜24 ブロック）を逆手に取り、理論最大 Occupancy を 75% にあえて固定。1スレッドあたりの割り当て可能レジスタ数を最大化し、**VRAM レジスタスピル完全ゼロ ＆ 超低レイテンシ実行** を達成。

### 生体膜アーキテクチャ（The Membrane Interface）
外周を厚さ 1 セルの仮想膜（`6 × 6 × 6 = 216` 要素、`groupshared half s_membrane[6][6][6]` : 432 Byte）で被覆。

- **直交6面通信（96セル） ＆ `half2` パッキング:**  
  面共有する直交 6 面（`4 × 4 × 6 = 96` セル）のみを通信対象とし、`half2`（32 bit）にパッキング（計 48 要素）。
  64 スレッド中、スレッド `0〜47` が 1 命令で隣接ブロックのデータを並列フェッチ。
- **角・辺のゼロパディングによる `if` 文撲滅:**  
  斜め方向の角（8 セル）および辺（48 セル）は `groupshared` 上に静的 `0.0` をパディング。思考核の 64 スレッドは境界判定の `if` 文を一切挟まず、**100% 同一の 27 近傍ステンシルループ（Pure SIMD）** を完走。
- **Snoop 型ロックフリー非同期メモリモデル:**  
  各ブロックは自身の外周セルのみを VRAM 上の専用バッファへ排他書き出し。隣接ブロックはそれを Read-Only で覗き見（Snoop）する。大域同期バリアや Ping-Pong バッファを完全排除しつつ、ハードウェア 32 bit アライメントによりビット引き裂き（Torn Read）と `NaN` 爆発を物理的に完全防止。

### 細胞極性と活性化関数
- **デールの原理（Dale's Principle）:**  
  興奮性 `[0.0, 1.0]`、抑制性（GABA） `[-1.0, 0.0]`、シナプス重み $W \in [0, 255]$（符号と太さの完全分離）。
- **生物学的 f-I 曲線（無料 ALU）:**  
  HLSL 組み込み修飾子 `saturate()` による ALU 追加コスト実質ゼロでの実行。
  - 興奮性:
    $$out = \text{saturate}(net - \text{threshold})$$
  - 抑制性:
    $$out = -\text{saturate}(net - \text{threshold})$$

### 配線トポロジー：スモールワールド創発
- **局所 27 近傍 ＋ 28 番結合（内部ショートカット）:**  
  28 番目の軸索は、同一ブロック（ $4 \times 4 \times 4$ ）内部の非近傍セルへ確率的に配線。
  ブロック間を跨ぐ「直交面の局所拡散」と、ブロック内部の「28 番高速ショートカット」が組み合わさることで、神経解剖学的な **スモールワールド・ネットワーク（Small-world network）** を自律形成。

## 3. 発生ゲノムと三要素シナプス可塑性

### 階層的メモリモデル（超極小ゲノム ＆ 動的重みバッファ）
- **超極小ゲノム（64 Byte / `float4` × 4本）:**  
  発生ルールと形態形成シードのみを間接符号化。全個体の DNA が GPU の L2 キャッシュに完全常駐。
- **動的重み実体バッファ（1脳あたり 1,792 Byte）:**  
  各セル 28 結合の重み（ $64 \times 28 = 1,792$ Byte）を VRAM 上に実体保持。初期重みはゲノム親和性からプロシージャル展開され、以降はヘッブ可塑性によって現場で連続書き換え。

### 1 クロック MADD 線形合同法による確率的丸め（Stochastic Rounding）
`uint8` の微小更新 $\Delta W$ のアンダーフローおよびシナプス間の共分散（道連れ現象）を排除するため、GPU ハードウェアの積和算命令（MADD）に直結した線形合同法（LCG）を採用。

```hlsl
// スレッド初期化時にセル固有シードを生成
uint seed = thread_id + time_step_hash;

// シナプスループ内で 1 クロック更新（Numerical Recipes / Knuth 定数）
seed = seed * 1664525u + 1013904223u;
uint rnd8 = (seed >> 24); // 上位 8 bit の高品質一様乱数

// 8 bit 分解能での確率的切り上げ
if (delta_w_fraction > rnd8) {
    W[i] += 1;
}
```

### 三要素ヘッブ学習則 ＆ 内生ドーパミン核

$$\Delta W_{ij} = \eta \cdot \text{Dopamine} \cdot (x_i \cdot x_j) - \lambda W_{ij}$$

- **恒常性減衰 $\lambda$:** シナプスの過剰飽和を防ぐ代謝忘却。
- **内生ドーパミン核（中脳 VTA モデル / RPE）:**  
  特定セルを報酬予測誤差（RPE）出力核に指定。局所適格度トレースの「時間のドミノ倒し」により、過去ログの再生バッファなしで数秒〜数分の時間軸延伸を実現。

## 4. 創発的制御と身体性（Locomotion & Safety）

- **非線形拡張 PID の創発:**  
  P（不感帯付き非線形直結）、D（分数階微分ダイナミクス）、I（Leaky Integrator / ReLU 飽和と減衰 $\lambda$ によるアンチワインドアップ自己消滅）。
- **マウスナー反射弓（1 ステップ緊急回避）:**  
  感覚入力直結の高閾値セルから 28 番ショートカットを経て運動出力へ 1 ステップ点火。脱輪や衝突のサージ時のみ超信地旋回を発火。
- **脊髄 CPG 歩行（体節モジュラー結合）:**  
  脚ごとに $4 \times 4 \times 4$ を配置し、生体膜の面通信で緩く連成。蔵本モデル的位相同期による歩行パターンの自律創発。
- **事後学習トグル（産業安全規格 ISO 3691-4 準拠）:**  
  - **訓練環境:** 学習 ON（ $\eta > 0$ ）で物理環境に極限適応。
  - **本番環境:** 学習 OFF（ $\eta = 0$ ）で重みを冷凍。100% 決定論的・有界可塑性のホワイトボックスコントローラとして運用。

## 5. スケーリング・トポロジーと器官スタック

- **単一カーネルの普遍性（Single Universal Kernel）:**  
  1 ブロックでも数百万ブロックでも、内部ニューロンのシェーダーコードは完全不変。
- **大脳皮質化（網膜部位局在シート）:**  
  ファミコン解像度（ $256 \times 240$ ）を $4 \times 4$ パッチで受容 $\rightarrow$ **ジャスト 3,840 ブロック（Dispatch(64, 60, 1) / 約24万スレッド）** で CNN を介さず直接視覚野を構成。
- **菌糸ネットワーク（Wood Wide Web）:**  
  ブロックを鎖状に直列結合し、活動電位の非線形パルス伝播と In-Network Computing を実現。
- **器官の重ね合わせ（Layered Voxel）:**  
  脳ブロック上にセンサ・アクチュエータ・バッテリー等の器官メタデータをスタック。形態とエネルギーの物理的トレードオフに基づく種分化を誘導。
